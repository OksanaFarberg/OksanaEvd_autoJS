# Проект "Автоматизация тестирования API для электронной библиотеки""
 
Этот проект предназначен для автоматизации тестирования API с использованием JavaScript и библиотеки Jest.   
Тесты проверяют функциональность API и помогают убедиться в корректной работе системы.
 
### Структура проекта:

      test/ — директория, содержащая тестовые файлы
      package.json — файл с конфигурацией проекта и зависимостями
      jest.config.js — конфигурация для Jest, включая настройки репортера


## Важно:
   
   Перед тем как запустить проект, убедитесь, что установлен Node.js:  
   Проверить версию node: **node -v**  
   Проверить версию npm: **npm -v**


## Установка

Чтобы установить проект, выполните следующие шаги:

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/OksanaFarberg/OksanaEvd_autoJS.git

2. Перейдите в каталог проекта:
   ```bash
   cd OksanaEvd_autoJS

3. Установите зависимости:
   ```bash
    - npm init -y
    - npm install
    - npm install dotenv

4. Запуск тестов
    ```bash
    - npm run test
